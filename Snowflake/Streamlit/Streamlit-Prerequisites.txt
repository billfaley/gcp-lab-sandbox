* Use Anaconda to configure an environment for Streamlit
    docs.streamlit.io/get-started/installation/anaconda-distribution#create-an-environment-using-anaconda-navigator


* Install Streamlit 
    >> https://docs.streamlit.io/get-started/installation/anaconda-distribution

    pip install streamlit

    To validate your installation, enter:

    streamlit hello

* First App

    Copy the following code into app.py and save it.

        import streamlit as st

        st.write("Hello World")

APPENDIX


* Install conda package manager

    https://docs.anaconda.com/miniconda/install/#quick-command-line-install
    curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh

    installation finished.
    Do you wish to update your shell profile to automatically initialize conda?
    This will activate conda on startup and change the command prompt when activated.
    If you'd prefer that conda's base environment not be activated on startup,
    run the following command when conda is activated:

    conda config --set auto_activate_base false

    You can undo this by running `conda init --reverse $SHELL`? [yes|no]
    yes

    >> Review cheatsheet: https://docs.conda.io/projects/conda/en/latest/user-guide/cheatsheet.html


* Configure conda environment (OPTIONAL - is done automatically with miniconda install)
    conda create --name <my-env>
        e.g. conda create --name my-base-conda-env
